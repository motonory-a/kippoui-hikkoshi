# @kaiun_hikkoshi 投稿画像の作り方（Claude用）

- 画像：`python3 ig/tool/render.py spec.json ig/wN` で 1080×1350 のJPGを作る（要 playwright・Noto CJKフォント）。
- spec.json の形：`{"slides":[{"id":"k1","cat":"金運","sub":"保存版","title":"金運が<br>上がる方角は<br><em>どっち？</em>","size":72,"navi":"n2","body":{"type":"duo","a":"西","at":"お金が<br>入ってくる","b":"北西","bt":"仕事で<br>成功する","warn":true}}]}`
  - body.type：`lead`（html）／`list`（items=[[見出し,説明],...]、red/tight/big）／`duo`（2方角の比較＋注意書き）／`banner`
  - navi：n1 満面の笑顔・n2 ウインク・n3 驚き・n4 考える・n5 ほほえみ・02 指さし・04 鍵を差し出す
  - 見出しは3行まで。`<em>` がオレンジ＋黄マーカー。NG(はみ出し) が出たら文字を減らすか size を下げる
- オフショット写真の投稿画像：`python3 ig/tool/render_photo.py photo.json ig/wN`（写真を全面、角に小さなカードだけ。顔と体にかからない角を pos で選ぶ）。文字の説明は render.py で別の画像にして、2枚目以降に並べる。
- 公開URL：https://motonory-a.github.io/kippoui-hikkoshi/ig/wN/xxx.jpg（push後1分ほどで有効）

## 決まり（本人と決めたこと）
- 案内役はナビ子。明るい女性。基本はバストアップ
- 文章は短く言い切る。むずかしい言葉を使わない（方違え→寄り道引越し、吉方位→いい方角）。締めは「サイトで確認しましょう」「プロフィールのリンクから無料で」
- 九星気学の内容は「〜と言われています」。予言のような断定はしない。でたらめを書かない
- 金運・恋愛運は人気なので1週7本のうち各2本、残り3本は引越しの基本・季節の話題
- AI画像なので instagramData.isAiGenerated=true。毎晩21:30（Asia/Tokyo）に投稿
- ハッシュタグ6〜7個（#吉方位 #引越し #開運 #九星気学 など。不動産向けに #住み替え #物件探し も）

## ナビ子のオフショット（本人提供 2026-11-15、使える時に使う）
- `ig/tool/offshot/garden-orange-dress.png`：花の庭でオレンジのワンピース、麦わら帽子。春〜初夏、休日、恋愛運・出会い、「ナビ子のおやすみの日」など、やわらかい話題に。
- `ig/tool/offshot/resort-pool-swimwear.png`：リゾートのプールサイドで紺の水着に白いシャツ。夏（6〜8月）、旅行・リゾート・南の方角の話題のときだけ使う。季節外れには使わない。
- 使い方：月に1〜2回程度、ふだんの案内役（ジャケット姿）との“ギャップ”で親しみを出す。写真を主役に全面で使い、文字は小さなカードに。顔と体に文字を重ねない。
- 文章は品よく、明るく。体つきや色っぽさに触れる言葉、性的に受け取られる言い回しは使わない。AI画像なので isAiGenerated=true。

## 毎週の新しいオフショット（2026-11-15から）
- ChatGPT が毎週日曜9時ごろ、ナビ子のオフショットを2枚作り、Googleドライブ「AI共有／ナビ子_オフショット」（folder id 110f535QnDNtK191b_ES-vdI3vIy2Mt-y）に、制作日のフォルダごと保存する。基準は「00_キャラクター基準と見本」（id 1rO8RASaWDxiczbMeRaY8EAT4Hm9Vs-4T）。
- 投稿を作るときは、制作日が新しいフォルダから確認し、季節と話題に合うものを使う（週に1〜2本が目安）。使ったら、その画像を ig/tool/offshot/ にも保存する。
- 受け取った画像を作り直したり、顔・体形を変えたりしない。画像に文字やロゴは入っていないので、文字は投稿画像側のカードに入れる。
- 上品な大人っぽいショットも、文章は明るく品よく。体つきや色っぽさに触れる言葉は使わない。AI情報（isAiGenerated=true）をつける。
- 画像のフォルダが空・読めないときは、オフショットを使わずに通常の投稿で作る。
